PDF online zusammenfügen kostenlos — ohne Registrierung und Server-Upload

Müssen Sie mehrere PDF-Dateien zu einem Dokument zusammenfügen? Mit marge-PDF dauert das nur wenige Klicks — direkt im Browser, ohne Registrierung, ohne E-Mail und ohne Ihre Dateien auf einen fremden Server hochzuladen.

So fügen Sie PDF zusammen — 3 einfache Schritte

  1. Öffnen Sie das Werkzeug "PDF zusammenfügen" — klicken Sie auf das Symbol auf der Startseite.
  2. Ziehen Sie Ihre Dateien hinein — wählen Sie zwei oder mehr PDFs. Die Reihenfolge ändern Sie durch Ziehen am Griff ⋮⋮.
  3. Laden Sie das Ergebnis herunter — klicken Sie auf "Ausführen" und erhalten Sie die zusammengefügte Datei.

Das war's. Keine Registrierung, keine E-Mail-Bestätigung, kein "Wählen Sie Ihren Tarif".

Warum marge-PDF und nicht iLovePDF oder Smallpdf

Die meisten Online-PDF-Dienste laden Ihre Dateien auf ihre Server hoch. Selbst wenn sie versprechen, sie "in einer Stunde zu löschen" — in dieser Stunde liegt Ihr Dokument auf einem fremden Computer. Bei Verträgen, Rechnungen, Pässen oder Geschäftsgeheimnissen ist das ein echtes Risiko.

marge-PDF funktioniert anders:

  • Ihre Dateien verlassen nie Ihr Gerät. Alles geschieht in Ihrem Browser. Sie können sogar das Internet ausschalten, nachdem die Seite geladen ist — das Werkzeug läuft weiter.
  • Keine Registrierung. Keine E-Mail, kein Passwort, keine Telefonbestätigung.
  • Keine Limits. Kein "3 Dateien pro Tag" oder "max. 10 MB". Fügen Sie 5, 10 oder 50 PDFs zusammen.
  • Für immer kostenlos. Unterstützt durch freiwillige Spenden — kein Abo nötig.
💡 Tipp: Für sehr große PDFs (100+ MB) verwenden Sie besser einen Computer statt eines Handys — Browser brauchen mehr Speicher.

Häufige Fragen

Gibt es ein Limit bei der Anzahl der Dateien?

Nein. Fügen Sie so viele zusammen, wie Sie brauchen.

Was ist die maximale Größe einer einzelnen PDF?

Die Grenze ist der Arbeitsspeicher Ihres Geräts. Normalerweise 500 MB–1 GB. Weniger auf einem schwachen Handy.

Was passiert mit meinen Dateien nach dem Zusammenfügen?

Nichts. Sie bleiben auf Ihrem Gerät — nichts wird irgendwohin gesendet. Nach dem Schließen des Tabs verschwindet alles aus dem Browser-Speicher.

Kann ich passwortgeschützte PDFs zusammenfügen?

Wenn eine PDF passwortgeschützt ist, entfernen Sie zuerst den Schutz mit dem Werkzeug Protect PDF, dann fügen Sie zusammen.

Funktioniert es auf dem Handy?

Ja. Öffnen Sie die Seite in Safari (iPhone) oder Chrome (Android) — alles funktioniert gleich.

Was marge-PDF sonst noch kann

  • PDF teilen — einen Seitenbereich extrahieren
  • PDF komprimieren — Dateigröße reduzieren
  • Text auf PDF bearbeiten — vorhandenen Text ändern
  • Unterschrift hinzufügen — zeichnen, tippen oder hochladen
  • PDF zu JPG — jede Seite als Bild
  • Wasserzeichen — mit Text schützen
