PDF komprimieren — kleinere Datei, nichts wird hochgeladen

PDF zu groß für die E-Mail? marge-PDF verkleinert sie direkt im Browser, das Dokument wird nicht an einen Server gesendet.

Werkzeug öffnen →

So geht's — 3 Schritte

  1. Öffnen Sie das Werkzeug „PDF komprimieren“ und fügen Sie Ihre Datei hinzu.
  2. Starten Sie die Komprimierung und warten Sie einige Sekunden.
  3. Laden Sie die kleinere Datei herunter und vergleichen Sie sie mit dem Original.

Warum marge-PDF

Ihre Dateien verlassen Ihr Gerät nicht: alles läuft im Browser. Ohne Anmeldung, ohne Limits, kostenlos.

Häufige Fragen

Wie viel kleiner wird die Datei?

Das hängt vom Inhalt ab: Scans und bildlastige PDFs schrumpfen am stärksten, reine Textdateien deutlich weniger. Bewahren Sie das Original auf, falls Sie die volle Qualität brauchen.

Werden meine Dateien hochgeladen?

Nein. Die Verarbeitung läuft in Ihrem Browser, das Dokument bleibt auf Ihrem Gerät.
