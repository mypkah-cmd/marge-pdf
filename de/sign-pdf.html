PDF unterschreiben online — zeichnen, tippen oder hochladen

Müssen Sie einen Vertrag, eine Einwilligung oder ein NDA unterschreiben, aber kein Drucker in der Nähe? Mit marge-PDF unterschreiben Sie direkt im Browser — in 30 Sekunden, ohne Anmeldung und ohne Ihre Dateien auf einen fremden Server hochzuladen.

So unterschreiben Sie ein PDF — 3 einfache Schritte

  1. Öffnen Sie das Werkzeug „Unterschrift" — klicken Sie auf das Symbol ✍️ auf der Startseite.
  2. Erstellen Sie Ihre Unterschrift — wählen Sie eine von drei Möglichkeiten: mit Maus/Finger zeichnen, Namen in Schreibschrift tippen oder ein PNG-Bild hochladen.
  3. Auf dem PDF platzieren — klicken Sie auf die Seite, wo die Unterschrift hin soll, dann „Auf PDF platzieren" drücken.

Das war's. Keine Anmeldung, keine E-Mail-Bestätigung, kein „Wählen Sie Ihren Tarif".

Warum marge-PDF statt DocuSign oder Adobe Sign

Die meisten PDF-Unterschriftendienste laden Ihre Dokumente auf ihre Server hoch und verlangen ein Konto. DocuSign, Adobe Sign, SignNow — alle cloudbasiert. Bei einem NDA, einem Arbeitsvertrag oder einer persönlichen Einwilligung liegt Ihr Dokument auf einem fremden Computer.

marge-PDF funktioniert anders:

  • Ihre Dokumente verlassen nie Ihr Gerät. Alles geschieht im Browser. Trennen Sie nach dem Laden der Seite das Internet — es funktioniert weiter.
  • Keine Anmeldung. Kein Konto, keine E-Mail-Bestätigung, keine Telefonnummer.
  • Drei Unterschriftsmethoden. Mit Maus zeichnen, in Schreibschrift tippen oder PNG hochladen. Wählen Sie, was Ihnen passt.
  • Für immer kostenlos. DocuSign verlangt 10+ $/Monat für den Basisplan. Unser Tool ist kostenlos — kein Abonnement, keine Limits.
💡 Tipp: Für rechtlich bindende Dokumente benötigen Sie in manchen Ländern mehr als eine visuelle Unterschrift — möglicherweise ein digitales Zertifikat (QES/eIDAS). Prüfen Sie Ihre lokalen Vorschriften.

Häufig gestellte Fragen

Ist diese Unterschrift rechtlich gültig?

Für die meisten Alltagsfälle (Verträge zwischen Privatpersonen, interne Dokumente) — ja. Für strenge Rechtsfälle (notarielle Geschäfte, Bankverträge) kann ein digitales Zertifikat (QES/eIDAS) erforderlich sein — fragen Sie bei der Organisation nach.

Kann ich auf mehreren Seiten unterschreiben?

Ja. Nach dem Laden des PDFs klicken Sie auf jede Seite, wo eine Unterschrift nötig ist, dann „Auf PDF platzieren".

Bleibt die ursprüngliche PDF-Qualität erhalten?

Ja. Wir fügen die Unterschrift als Bild über die Seite ein. Der restliche Text, die Bilder und das Layout bleiben unangetastet.

Was, wenn die Unterschrift falsch platziert ist?

Laden Sie das PDF einfach neu und platzieren Sie erneut. Die Originaldatei wird erst geändert, wenn Sie „Auf PDF platzieren" drücken.

Funktioniert es auf dem Handy?

Ja. Sie können die Unterschrift mit dem Finger direkt auf dem Handy-Bildschirm zeichnen — ideal, wenn Sie unterwegs ein Dokument unterschreiben.

Was marge-PDF sonst noch kann

  • PDF zusammenführen — mehrere Dateien zu einer verbinden
  • Text in PDF bearbeiten — vorhandenen Text ändern
  • PDF teilen — einen Seitenbereich extrahieren
  • PDF komprimieren — Dateigröße reduzieren
  • PDF zu JPG — jede Seite als Bild
  • Wasserzeichen — mit Textstempel schützen
